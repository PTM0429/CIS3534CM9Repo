# CIS3534C GPA 9 - Git and GitHub

This repository contains the Python source code and data files from GPA 8.

## Files

- networkFileRW.py: Python program used to read and write network equipment information.
- equip_r.txt: Data file containing router equipment information.
- equip_s.txt: Data file containing switch equipment information.

## Purpose

The purpose of this project is to manage network equipment information using Python. This repository is also used to practice Git version control and GitHub collaboration.
